🎯 COMPONENTES IMPLEMENTADOS

CONTABILIDAD:
  ✅ JournalEntryList
     - Ruta: /companies/:companyId/accounting/journal-entries
     - Funciones: Listar, filtrar, paginar, navegar a detalle
     - Filtros: estado, origen, fecha desde/hasta

  ✅ JournalEntryDetail
     - Ruta: /companies/:companyId/accounting/journal-entries/:id
     - Funciones: Ver detalle, validar balance, aprobar, recalcular
     - Acciones: POST approve, POST recalculate
     - Modal: Confirmación + Observaciones

REPORTES:
  ✅ BalanceSheet
     - Ruta: /companies/:companyId/reports/balance
     - Secciones: Activo, Pasivo, Patrimonio Neto
     - Características: Expandible, validación de cuadre

  ✅ ProfitAndLoss
     - Ruta: /companies/:companyId/reports/profit-and-loss
     - Secciones: Ingresos, Gastos, Resultado Neto
     - Características: Margen de beneficio, visual en cajas

🎨 CARACTERÍSTICAS UI

Estados de Asiento:
  ✅ DRAFT           → Badge gris "Borrador"
  ⏳ PENDING_REVIEW  → Badge amarillo "Pendiente de Revisión"
  ✓ POSTED          → Badge verde "Contabilizado"
  ✗ REVERSED        → Badge rojo "Reversado"

Validaciones:
  ✅ Asiento cuadrado   → Alert success (fondo verde)
  ❌ Desbalanceado      → Alert error (fondo rojo)
  ⚠️ Errores validación → Alert warning (fondo amarillo)

Formateo:
  ✅ Números como EUR: 1.000,50 €
  ✅ Fechas locales: 13/06/2026
  ✅ Tablas striped (colores alternos)
  ✅ Modales con confirmación

🚀 INICIO RÁPIDO (5 pasos, 30 min)

1. npm install @chakra-ui/react @emotion/react @emotion/styled framer-motion

2. Configurar path aliases en tsconfig.json

3. Envolver App con <ChakraProvider> en main.tsx

4. Importar rutas en App.tsx:
   <Route path="/companies/:companyId">
     <Route path="accounting/*" element={<AccountingRoutes />} />
     <Route path="reports/*" element={<ReportsRoutes />} />
   </Route>

5. Crear .env:
   REACT_APP_API_URL=http://localhost:3000/api
